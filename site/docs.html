Pierwsze uruchomienie

  1. Przygotuj Tab5, kartę microSD FAT32, kabel USB-C z danymi i Chrome lub Edge na komputerze.
  2. Wgraj firmware 0.3. W oknie portów wybierz USB JTAG/serial debug unit; po zakończeniu zamknij okno flashowania.
  3. Pobierz jedną dokładnie wskazaną paczkę. Możesz zacząć od Sołtysa PL bez konta. Nie rozpakowuj ani nie uruchamiaj EXE/PKG.
  4. Wskaż plik, wybierz Sprawdź wybrane gry, potem Połącz Tab5 i dodaj gry. Poczekaj na zakończenie transferu.
  5. Dotknij okładki na Tab5, potem ▶. Kolejne gry dopiszesz później bez ponownego kopiowania biblioteki.

BASS i Amazon Queen są bezpłatne na GOG; Sam & Max, Indiana Jones, The Dig i Curse wymagają Twoich własnych wydań. Na GOG otwórz Download offline backup game installers → macOS → English, także jeśli używasz Windows. Pobierz dokładny PKG z tabeli. Loguj się wyłącznie na GOG. Strona odczytuje paczkę lokalnie, nie uruchamia jej ani nie wysyła gry lub danych konta na serwer. Hash potwierdza wydanie, nie własność konta.

Import The Dig i Curse (około 1 GB paczki) może potrwać przez USB kilkadziesiąt minut. Połączenie z instalatorem restartuje Tab5. Karta nie jest formatowana; istniejące gry, zapisy i profile są zachowywane. Nie odłączaj kabla ani karty podczas transferu.

W grze

Dotyk = lewy klik. POINTER wskazuje bez akcji, L CLICK i R CLICK to przyciski myszy, nie kierunki chodzenia. POINTER pokazuje ON/OFF, a ? otwiera pomoc. MENU otwiera Save/Load oraz Return to Launcher, SKIP wysyła Escape, KEYS otwiera klawiaturę. Nippon zapisuje przez KEYS → s → ✓; Curse wybiera Talk przez KEYS → t → ✓. Koło czynności Curse pojawia się po przytrzymaniu sceny, ale wybór gestem nie jest jeszcze zmierzony.

Wygląd i dźwięk

Settings → GUI → Theme: Light, Dark albo Black. Settings → Tab5 → Sidebars ustawia paski niezależnie. − / + zmienia głośność, MUTE / UNMUTE wycisza. Ustawienia zapisują się na karcie; odsłuch jakości audio nie jest zaliczony.

Gdy instalacja się zatrzyma

Przy braku portu sprawdź kabel danych i zamknij monitor szeregowy. Przy złym hashu pobierz dokładne wydanie; zmiana nazwy nie wystarczy. Przerwany własny import można ponowić tą samą paczką. Brak SD wymaga wyłączenia Tab5 i włożenia karty FAT32.

Your first adventure

  1. Prepare Tab5, a FAT32 microSD, a USB-C data cable and desktop Chrome or Edge.
  2. Install firmware 0.3 and select USB JTAG/serial debug unit. Close the flashing dialog when complete.
  3. Download one exact archive below. Start with free Sołtys if you like. Do not unpack it or run the original EXE/PKG.
  4. Select the file, verify it, then add it over USB. Wait for completion; large games may take tens of minutes.
  5. Tap its cover and ▶ on Tab5. Add more games later using the same flow.

BASS and Amazon Queen are free on GOG. Sam & Max, Indiana Jones, The Dig and Curse require your own GOG editions. In your GOG library choose Download offline backup game installers → macOS → English, even on a Windows computer. Sign in only at GOG. This page reads the PKG locally and sends game files straight to Tab5 over USB; it does not upload account data or prove ownership.

Connecting the game installer restarts Tab5. It does not format microSD; existing games, saves and profiles are retained. Keep power and card connected through transfer.

Controls

Tap for left click. POINTER points without clicking; L CLICK and R CLICK are mouse buttons, not walking directions. POINTER shows ON/OFF; ? opens control help. MENU opens Save/Load and Return to Launcher. SKIP sends Escape; KEYS opens the keyboard. Nippon saves with KEYS → s → ✓. In Curse, Talk works with KEYS → t → ✓. Holding a scene shows the verb coin, but gesture selection remains unmeasured.

Appearance and sound

Settings → GUI → Theme offers Light, Dark or Black; Settings → Tab5 → Sidebars sets sidebar colours separately. Volume − / + and MUTE / UNMUTE are on the sidebars. Audible-quality testing is still pending.

Recovery

Use a data cable and close other serial tools if the port is missing. Retry an interrupted project-managed copy with the same archive. An unknown edition is rejected. Missing SD does not trigger formatting. Keep your previous firmware image or vendor recovery instructions before the first flash.
